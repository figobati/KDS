# KDS 需求变更台账

> 单一真值：**外部群提出的每一条「要改」都从这里看**。详细内容见 `docs/requirements/changes/CR-<编号>-<slug>.md`。
> 台账只追加、不删行；状态变化直接改状态列，并在「内部结论」列写一句。

| 编号 | 提出日期 | 提出人 | 一句话诉求 | 影响面（初判） | 状态 | 内部结论 |
|---|---|---|---|---|---|---|

## 状态取值

| 状态 | 含义 | 谁能改 |
|---|---|---|
| 待内部评审 | 外部刚提，未讨论 | 外部群 PM 建 |
| 评审中 | 内部群正在谈设计与影响 | 内部群 PM |
| 已排期 | 定了做法，已进看板 | 内部群 PM |
| 不采纳 | 讨论后决定不做，需给客户理由 | 内部群 PM |
| 已上线 | 已交付到客户 | 内部群 PM |

## 约定

- 编号连续：`CR-001`、`CR-002`…，永不复用。
- 外部群**只建条目、不做评估**：不猜工期、不承诺、不谈设计。
- 内部群讨论时，先看本表「待内部评审」的行，谈完把结论写回本表 + 对应 CR 文件。
- CR 定案要改 PRD 的，按项目规则在 PRD 00 号文件追加一行变更，并在 CR 文件里写明 PRD 章节。
