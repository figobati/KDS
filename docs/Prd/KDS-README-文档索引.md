# KDS 厨房显示系统 — 文档索引

> **本目录是 PRD 与设计文档的拆分版**（v6.64 起）。
> 原合并版 `KDS-完整PRD与设计文档-v6.md` 保留为历史参照，**后续修改只落在拆分文件中**。

**技术栈**：**.NET 10（LTS）/ C# 14**　**数据库**：SQLite（门店默认）/ SQL Server **2016+（推荐，最低 2012）**；2008 暂不实现（见 07 号文件 §8.3.5，后期绕不开再评估）
**数据访问**：EF Core 10（写 + 迁移）+ Dapper（读 / 报表 / 批量），边界见 07 号文件 §8.4

**架构**：一个程序多角色（Master / Worker），按订单号分片队列

## 2. 编号约定（**跨文件引用有效**）

- 全文章节号 **全局唯一且连续**：`§2.16` 可能在 03 号文件里，但引用它时不用写文件名。
- 文件只是"物理切分"，**逻辑上仍是一份文档**：§ 编号、D 编号、表编号都不重排。
- 例：04 号文件 §3.5.4 提到"见 §2.19"，直接翻 03 号文件即可。

## 5. 维护规则

1. **只改拆分文件**，不回首改合并版（合并版仅作历史比对）。
2. 改动跨文件时，**同步检查引用**：`grep "§x.y"` 全文检索，避免出现指向旧结论的引用。
3. **新增章节**：追加到对应文件末尾，编号接着排（禁止重排既有编号，否则历史引用全断）。
4. **变更记录**：只在 `KDS-00-版本记录.md` 追加一行，写清"改了什么 + 为什么"。
5. **口径冲突**：一律以 §1.6 的 D 表为准，并**同时修正正文**（不允许只改一处）。
