# KDS 厨房显示系统 — 完整 PRD 与设计文档

> 版本：**v6.99**（v6.98 + **POS 能力声明表**：B-11/B-12/B-13 全关闭，**阻塞契约冻结项清零**）
> 技术栈：**.NET 10（LTS）/ C# 14**；EF Core 10 + Dapper
> 架构：一个程序多角色（Master / Worker），按订单号分片队列
> 数据库：SQLite（门店默认）/ SQL Server **2016+ 推荐、2012 最低**；2008 不实现（§8.3.3）
> 传输：HTTP + WebSocket（SignalR）/ MQTT 可配置
> 命名：JSON / DB / C# 统一 PascalCase；主键统一 GUID；**领域命名中性，不沿用任何 POS 的表名**（§9.0）
> 工作流：三角色屏（切配/制作/传菜）+ 品项自定义 StagePath + 档口反选关联模型
> 操作模式：品项到达屏幕即可直接划单；同档口多屏统一**广播**
> 菜品归类：合菜视图按**名字**归类（不按 UID），由 7 项合并条件决定 `MergeKey`（默认全开）
> 视图结构：**配置页二选一**（桌台模式 / 订单模式，订单 V2）+ **屏幕三视图实时切换**（基础分组 / 合菜 / 单菜）
> 流转开关：门店级 EnableWorkflowState + AutoFlowEnable
